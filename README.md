# Blood Analysis App

AI-powered web application for blood test analysis using Python, PDF parsing, and Machine Learning.

## Tech Stack

- Python
- pandas
- numpy
- scikit-learn
- Streamlit
- pdfplumber
- Plotly

## Project Structure

```text
blood-analysis-app/
│
├── app/
├── data/
├── notebooks/
├── src/
│   └── main.py
│
├── .gitignore
├── README.md
└── requirements.txt
```

## Setup

Create virtual environment:

```bash
py -3.11 -m venv .venv
```

Activate environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```
